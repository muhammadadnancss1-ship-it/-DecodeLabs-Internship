# Rule-Based AI Chatbot

A simple Rule-Based AI Chatbot developed using Python.  
This chatbot responds to predefined user inputs using `if-else` conditions and runs continuously until the user exits.

# Features

1 Handles greetings
2 Responds to predefined questions
3 Uses `if-else` decision-making logic
4 Runs in a continuous loop
5 Handles exit commands
6 Beginner-friendly AI project

# Technologies Used
Python 3
